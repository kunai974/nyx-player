Open & transparent

Nothing to hide.
Check for yourself.

Nyx Player is free software. Every line of code is public, and our apps are built in the open — so you never have to take our word for it.

Windows says “unknown publisher”?

That is normal for a new, independent app: Nyx is not yet signed with a paid Windows certificate. On the blue SmartScreen window, click More info, then Run anyway. You can verify what you run: the whole source is public and open to anyone.

Installing on Android & Android TV

Open the downloaded APK. If asked, allow installs from your browser or file manager (“unknown sources”) — you can switch it off again afterwards.

Verify your download

Each release on GitHub includes SHA256SUMS.txt, the SHA-256 fingerprint of every file. Compare it with your download. Every file also has a build certificate: check it with gh attestation verify <file> --repo kunai974/nyx-player.
