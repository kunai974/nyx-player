Nyx Player est un logiciel libre. Tout le code est public et nos applications sont construites au grand jour : vous n’avez pas à nous croire sur parole.

Windows affiche « éditeur inconnu » ?

C’est normal pour une application indépendante et récente : Nyx n’est pas encore signée avec un certificat Windows payant. Dans la fenêtre bleue SmartScreen, cliquez sur Informations complémentaires, puis Exécuter quand même. Vous pouvez vérifier ce que vous lancez : tout le code source est public.

Installer sur Android et Android TV

Ouvrez l’APK téléchargé. Si on vous le demande, autorisez les installations depuis votre navigateur ou votre gestionnaire de fichiers (« sources inconnues ») — vous pourrez le désactiver ensuite.

Vérifier votre téléchargement

Chaque version publiée sur GitHub contient SHA256SUMS.txt, l’empreinte SHA-256 de chaque fichier. Comparez-la avec votre téléchargement. Chaque fichier a aussi un certificat de fabrication : vérifiez-le avec gh attestation verify <fichier> --repo kunai974/nyx-player.
