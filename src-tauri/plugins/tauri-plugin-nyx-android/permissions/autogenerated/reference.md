## Default Permission

Player control, secure credential storage, app updates and event listeners for the Nyx Player Android bridge.

#### This default permission set includes the following:

- `allow-play`
- `allow-stop`
- `allow-set-paused`
- `allow-seek`
- `allow-set-volume`
- `allow-set-muted`
- `allow-set-speed`
- `allow-select-track`
- `allow-set-resize-mode`
- `allow-set-video-margins`
- `allow-set-subtitle-scale`
- `allow-set-fullscreen`
- `allow-get-property`
- `allow-network-status`
- `allow-note-exit-requested`
- `allow-device-info`
- `allow-last-exit-report`
- `allow-secure-get`
- `allow-secure-set`
- `allow-secure-delete`
- `allow-update-info`
- `allow-fetch-update-manifest`
- `allow-request-install-permission`
- `allow-download-update`
- `allow-install-update`
- `allow-register-listener`
- `allow-remove-listener`
